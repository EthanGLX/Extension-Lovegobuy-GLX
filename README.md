# Lovegobuy Link Redirect

Propose de rediriger les liens Weidian, Taobao et 1688 vers Lovegobuy.

## Installation

1. Téléchargez et décompressez le fichier zip depuis la page Releases
2. Ouvrez `chrome://extensions/` dans Chrome
3. Activez le « Mode développeur »
4. Cliquez sur « Charger l'extension non empaquetée » et sélectionnez le dossier décompressé

## Utilisation

Quand vous ouvrez un lien Weidian, Taobao ou 1688, une fenêtre vous demande si vous voulez être redirigé vers Lovegobuy. Cliquez sur « Oui » pour continuer ou « Non » pour annuler.
