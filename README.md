# Extension-Lovegobuy-GLX
Version initiale v1.0 Redirige tes liens Weidian, Taobao et 1688 vers Lovegobuy (avec confirmation). Installation :  Télécharge et décompresse le ZIP.  Va sur chrome://extensions/ et active le Mode développeur.  Clique sur "Charger l'extension non empaquetée" et choisis le dossier.
